Overview
This project is a phishing-awareness presentation designed to explain how phishing attacks work, how to recognize suspicious messages, and how to respond safely.
Topics Covered
What phishing is
Email phishing, spear phishing, smishing, and vishing
The five stages of a phishing attack
Social-engineering tactics: urgency, authority, fear, greed, and trust
Warning signs in suspicious emails and links
SMS and phone scams, including KYC and OTP-related scams
Real-world examples involving Target, John Podesta, and Twitter
The Stop–Look–Verify–Report habit
Cybersecurity best practices
What to do after clicking a suspicious link
A five-question knowledge quiz
Key takeaways
How to Use the Presentation
Download the PowerPoint file from the repository.
Open it in Microsoft PowerPoint or a compatible presentation application.
Start Slide Show mode to present the slides.
Test the quiz navigation and answer controls in your presentation software before presenting.
Key Safety Messages
Pause before clicking links or opening attachments.
Check the sender, link, and message tone.
Verify requests using an official app, website, or known phone number.
Never share your OTP, PIN, CVV, or password.
Report suspicious messages to your IT team or bank.
In India, report cyber financial fraud at https://cybercrime.gov.in/ or call 1930.
